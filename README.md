# 麻雀点数計算機

実際に上がった手牌(面子・雀頭・アガリ牌)を入力すると、役の判定から翻数・符・点数までを自動計算するWebアプリです。

## 使い方

`index.html` をブラウザで開くだけで動きます。インストール不要。

1. 「状況」で親・子、場風・自風、ロン/ツモ、面前/副露、リーチの状態を選ぶ
2. 「ドラ」でドラ・赤ドラ・裏ドラの枚数を入力
3. 「手牌」で面子1〜4と雀頭を実際の牌(萬子/筒子/索子/字牌)で組み、どの面子でアガったか(アガリ牌)を指定
4. 役・翻数・符・点数・支払い内訳が自動で表示される

七対子・国士無双は「手牌」欄の切り替えボタンで専用の入力モードになります。

## 機能

- 面子・雀頭を実際の牌で入力するだけで、平和・断幺九・役牌・混一色/清一色・一気通貫・三色同順/同刻・対々和・三暗刻・混全帯幺九/純全帯幺九・小三元/大三元・小四喜/大四喜・字一色・清老頭・緑一色・四槓子・四暗刻(単騎判定つき)など主要な役をすべて自動判定
- 符も自動計算(待ちの種類、雀頭の役牌判定、面子の暗刻/明刻/槓子を判定)
- ロンで刻子を完成させた場合は明刻扱いになる、平和ツモは自摸符が付かないなど、実戦の細かいルールに対応
- 七対子・国士無双(十三面待ちの自動判定つき)の専用入力モード
- 満貫・跳満・倍満・三倍満・役満・数え役満などの点数区分と、ロン/ツモの支払い内訳を表示
- 直近8件の計算履歴をブラウザ内(localStorage)に保存

## ファイル構成

```
mahjong-score-vanilla/
├── index.html         # メインHTML
├── css/
│   └── style.css      # スタイル
├── js/
│   ├── engine.js       # 役判定・符計算・点数計算ロジック(DOM非依存)
│   └── app.js          # 画面描画・イベント処理
├── assets/
│   └── favicon.svg
└── README.md
```

## 技術

HTML / CSS / JavaScript(ライブラリ・フレームワーク不使用)

`js/engine.js` は純粋関数のみで構成されており、DOMに依存しないため単体でロジックのテストが可能です。

## デプロイ

GitHub Pages で公開できます。

1. GitHubにリポジトリを作成してプッシュ
2. Settings → Pages → Branch: main / root を選択
3. 公開URLをポートフォリオに記載
